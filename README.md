# Sage — Health & Fitness Tracker

A personal health tracker that logs weight, meals, exercise, water intake, and sleep — with correlation insights and monthly reports.

## Setup

1. Replace `PASTE_YOUR_URL_HERE` in `src/App.jsx` with your Google Apps Script Web App URL
2. Run `npm install`
3. Run `npm start` for local development
4. Deploy to Vercel for mobile access
